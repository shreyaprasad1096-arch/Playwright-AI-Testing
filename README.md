# Playwright E-commerce Tests

A TypeScript Playwright test project for an e-commerce application.

## Setup

```bash
npm install
npx playwright install
```

Set the application URL in `.env` or pass it when running tests:

```bash

```

## Run tests

```bash
npm test
npm run test:headed
npm run test:ui
npm run report
```

The initial spec checks that the storefront loads a page with a catalog-style title and a visible main content region. Update `tests/ecommerce.spec.ts` as the application selectors and user journeys become known.
